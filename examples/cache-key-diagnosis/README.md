# Cache-key diagnosis evidence bundle

This example models an engineering incident in which a report keeps returning
stale output after its source revision changes. An AI diagnostician asserts a
possible cause. An external check—not the model's confidence—controls whether
the application may treat that cause as supported.

The resulting directory is a complete, closed Itself evidence bundle. It
follows the diagnosis from the initial assertion through expected observations,
a controlled check, external evidence, evaluation, authorized state changes,
and an application decision.

The example is deliberately deterministic and provider-neutral. The model
assertion is produced by a transparent software fixture so the bundle can be
regenerated byte-for-byte without a credential, network call, or hidden
provider behavior. It is not presented as a hosted-model result.

## Verify it

From the repository root:

```bash
uv run --frozen itself bundle validate examples/cache-key-diagnosis/bundle
```

The validator independently checks:

- the bundle manifest and content-derived bundle identifier;
- the exact file inventory, byte lengths, and SHA-256 digests;
- all protocol records and cross-record references in `ledger.jsonl`;
- deterministic epistemic-state replay;
- the reasoning receipt's exact binding to the ledger;
- every ledger artifact reference against a materialized bundle file.

## Inspect it

The bundle contains:

- `inputs/diagnosis-request.json`: the information supplied to the
  diagnostician;
- `artifacts/model-assertion.json`: the non-authoritative structured assertion;
- `ledger.jsonl`: the complete 23-record evidence history;
- `reasoning-receipt.json`: a minimized, deterministic projection of that
  history;
- `bundle.json`: the digest-bound inventory and bundle identity.

Useful inspection commands:

```bash
uv run --frozen itself ledger replay \
  examples/cache-key-diagnosis/bundle/ledger.jsonl
uv run --frozen itself ledger summary \
  examples/cache-key-diagnosis/bundle/ledger.jsonl
uv run --frozen itself receipt validate \
  examples/cache-key-diagnosis/bundle/reasoning-receipt.json \
  --ledger examples/cache-key-diagnosis/bundle/ledger.jsonl
```

## Regenerate it

Generate the same logical example into a new directory:

```bash
mkdir -p .itself/examples

uv run --frozen python examples/cache-key-diagnosis/build_bundle.py \
  --output .itself/examples/cache-key-bundle
```

The builder refuses to overwrite an existing path.

The example builder uses the same public `EvidenceBundleBuilder` API exposed to
applications; it contains only case-specific record and artifact preparation.
